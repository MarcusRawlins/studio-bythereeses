# Reese Photography CRM Product Brief

Reese Photography CRM is a private, local-first CRM for Tyler Reese's photography business. It manages photography projects, clients, secure client portals, proposals, contracts, invoices, questionnaires, scheduling, and eventually an MCP interface for AI-assisted operations.

The first MVP proves the core trust boundary: Tyler can create a project/client record, generate a project-scoped magic link, and a client can view only their own project through a remembered portal session.

## MVP Goals

- Create and view projects.
- Create/link clients at project creation.
- Generate revocable magic links.
- Set 30-day portal cookies.
- Show a client project portal.
- Record audit events for admin and portal activity.

## Later Phases

- Proposals with editable sections.
- Native contracts and signing.
- Stripe invoices with retainers/installments.
- Questionnaires and derived timeline/formal-list outputs.
- Google Calendar scheduling.
- MCP server for controlled project/client actions.
